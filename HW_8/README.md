# LungPrometheus

**LungPrometheus** — сервис для хранения, просмотра и анализа КТ-исследований легких.

После загрузки исследования сервис подсвечивает патологию, если она есть, позволяет просматривать само исследование и автоматически формирует текстовое заключение при помощи локальной LLM через Ollama.

---

## Возможности

### Просмотр КТ

- загрузка отдельных DICOM-файлов;
- загрузка серии DICOM;
- поддержка исследований в формате `.mhd + .raw`;
- загрузка всей папки исследования;
- просмотр срезов;
- масштабирование изображения.

### Анализ

- запуск анализа исследования;
- выполнение анализа в фоне через очередь задач;
- масштабирование числа воркеров модели;
- отображение найденных объектов;
- возможность добавить находку вручную.

### Пользователи

- регистрация;
- авторизация;
- тестовый баланс пользователя;
- списание стоимости анализа — 80 ₽;
- заполнение данных пациента перед загрузкой исследования.

### Генерация заключения

После завершения анализа сервис обращается к отдельному FastAPI-приложению, которое взаимодействует с Ollama и формирует текстовое заключение.

Если Ollama недоступна, используется резервный шаблон заключения, поэтому демонстрационная версия продолжает работать без ошибок.

## Основные сущности

Проект использует три основные доменные модели.

### Study

Хранит информацию об исследовании пациента:

- данные пациента;
- описание исследования;
- текущий статус анализа.

### Finding

Представляет найденный патологический объект.

Может быть:

- автоматически создан моделью;
- добавлен врачом вручную.

### AnalysisJob

Описывает задачу анализа, которую обрабатывает один из фоновых воркеров.

## Хранение данных

Используется SQLite.

При первом запуске автоматически создаются таблицы:

- `users`;
- `studies`;
- `findings`;
- `analysis_jobs`.

База данных по умолчанию находится по адресу:

```text
data/app.sqlite3
```

## REST API

### Авторизация

| Метод | URL | Назначение |
| --- | --- | --- |
| `POST` | `/api/auth/register` | Регистрация пользователя |
| `POST` | `/api/auth/login` | Вход пользователя |
| `GET` | `/api/auth/me` | Получение текущего пользователя |

### Баланс

| Метод | URL | Назначение |
| --- | --- | --- |
| `POST` | `/api/balance/top-up` | Тестовое пополнение баланса |

### Исследования

| Метод | URL | Назначение |
| --- | --- | --- |
| `GET` | `/api/studies` | Получить список исследований |
| `POST` | `/api/studies` | Создать исследование |
| `GET` | `/api/studies/{id}` | Получить исследование |
| `DELETE` | `/api/studies/{id}` | Удалить исследование |

### Находки

| Метод | URL | Назначение |
| --- | --- | --- |
| `POST` | `/api/studies/{id}/findings` | Добавить находку вручную |

### Анализ

| Метод | URL | Назначение |
| --- | --- | --- |
| `POST` | `/api/studies/{id}/analyze` | Запустить анализ исследования |
| `GET` | `/api/jobs/{id}` | Проверить статус задачи |
| `POST` | `/api/viewer/analyze` | Найти объект для подсветки в загруженных срезах |

### Заключение

| Метод | URL | Назначение |
| --- | --- | --- |
| `POST` | `/api/reports/generate` | Создать заключение через FastAPI/Ollama |

## Пример работы через API

Вход под тестовым пользователем:

```bash
curl -X POST http://127.0.0.1:8765/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin"}'
```

Пополнение тестового баланса:

```bash
curl -X POST http://127.0.0.1:8765/api/balance/top-up \
  -H "Content-Type: application/json" \
  -H "X-Auth-Token: TOKEN" \
  -d '{"amount":80}'
```

Создание исследования:

```bash
curl -X POST http://127.0.0.1:8765/api/studies \
  -H "Content-Type: application/json" \
  -H "X-Auth-Token: TOKEN" \
  -d '{"patient_name":"Иван Петров","patient_id":"P-001","description":"КТ грудной клетки"}'
```

## Быстрый старт

Запуск основного сервиса:

```bash
python3 backend/server.py
```

Запуск сервиса генерации заключений:

```bash
uvicorn backend.report_service:app --host 127.0.0.1 --port 8766
```

При использовании локальной Ollama:

```bash
ollama serve
ollama pull llama3.1
```

По умолчанию используются:

```text
OLLAMA_URL=http://127.0.0.1:11434/api/generate
OLLAMA_MODEL=llama3.1
```

После запуска интерфейс доступен по адресу:

```text
http://127.0.0.1:8765
```

Порт, путь к базе данных и количество воркеров можно изменить при запуске:

```bash
python3 backend/server.py --port 9000 --db data/demo.sqlite3 --workers 4
```

## Docker

Сборка и запуск:

```bash
docker compose up --build
```

Сервис будет доступен по адресу:

```text
http://127.0.0.1:8765
```

Количество воркеров модели задается в `docker-compose.yml`:

```yaml
environment:
  MODEL_WORKERS: 2
```

Чтобы увеличить число воркеров, измените значение переменной, например на `4`, и перезапустите контейнер.
