# Веса модели

Файлы чекпоинтов (`*.pth`) намеренно не хранятся в репозитории — они большие
и не являются частью исходного кода. Положите сюда свой чекпоинт и укажите
путь к нему через переменную окружения `MODEL_WEIGHTS_PATH` (см. корневой
`README.md`, раздел «Модель»).

Ожидаемое имя по умолчанию (см. `docker-compose.yml`):

```text
backend/weights/improved_3dcnn_checkpoint.pth
```
